# Asset map · Cinna stickers

All assets are local, transparent WebP files inside `assets/stickers/`. Both dashboard and `stickers.html` use relative paths, so deployment needs the directory intact. The character is unofficial fan art © Sanrio.

| File | Dashboard use beyond the sticker book |
|---|---|
| `hello.webp` | Mood, greeting, reminder, dialog, favicon |
| `bouncy.webp` | Income record, sync mascot, playful mood |
| `cheer.webp` | Savings record, happy mood, FAB |
| `grumpy.webp` | Expense record, budget warning, grumpy mood |
| `cinna-snooze.webp` | Chart/empty state, dashboard preview |
| `cinna-bashful.webp` | Transaction corner decor and edit-information modal |
| `cinna-skateboard.webp` | Daily chart highlight and transport budget |
| `cinna-cupid.webp` | Letter, birthday-feeling corner accents, arisan icon |
| `cinna-royal.webp` | Spending metric and food budget |
| `cinna-colorful.webp` | Savings illustration and makeup budget |
| `cinna-giggle.webp` | Income metric, teeth category, category empty state |
| `cinna-cloud-friends.webp` | Compact welcome banner and preview |
| `cinna-tiny-hug.webp` | Savings metric |
| `cinna-shy.webp` | Cash-flow metric and makeup icon |
| `cinna-smile.webp` | Brand mascot and sticker décor |
| `cinna-blue-hug.webp` | Sync details, sleepy companion |
| `cinna-pixel.webp` | Hero corner and gallery teaser |
| `cinna-classic.webp` | Budget decoration and unmatched expense category |

`assets/saku-nopal-icon.svg` remains for the separate Nopal theme. The 14 newly supplied transparent pictures also appear as tiles on the standalone `stickers.html` page.
